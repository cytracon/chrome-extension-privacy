Privacy Policy — Archive Jump

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 6 September 2026

What the extension does

Archive Jump opens the current page in archive.today mirrors or the Wayback Machine. Settings can sync through a JSON file in your Google Drive plugin folder via a local native host.

Data collected

  • The URL you ask to archive, used only to build archive/Wayback links
  • Your settings (preferred mirror, badge mode, extra hosts)

Storage and sharing

  • Settings are stored in Chrome extension storage.
  • Sync writes settings-state.json via native host com.cytracon.plugin_sync.
  • Archive and Wayback requests go to those public archive services, not to Cytracon.

Permissions

  • storage — settings
  • activeTab / tabs / contextMenus — archive the current page or a link
  • nativeMessaging — Drive folder settings sync
  • alarms — periodic settings sync

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

You can use the extension locally, export a backup, or uninstall it to remove local extension data from Chrome. Synced JSON files live in your own Google Drive folder and can be deleted there.

Changes

If this policy changes, this page will be updated and the effective date will change.
