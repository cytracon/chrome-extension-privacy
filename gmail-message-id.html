Privacy Policy — Gmail Message ID

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 25 September 2026

What the extension does

Gmail Message ID is a Chrome extension that shows the thread ID and message IDs of the email currently open on mail.google.com and lets you copy them.

Data collected

The extension reads, only on mail.google.com and only in your browser:

  • the thread ID from the Gmail URL
  • message IDs already present in the Gmail page (data-legacy-message-id, data-message-id)
  • in versions before 1.1.0 only, the panel position in sessionStorage for the current tab session

It does not collect names, email bodies, attachments, contacts, or Google account credentials.

How data is used

From version 1.1.0, IDs are displayed locally in each expanded Gmail message header so you can copy them. Earlier versions use a floating panel. Nothing is sent to Cytracon or any other server. There is no analytics, advertising, or profiling.

Storage and sharing

  • IDs are not stored after you close the tab.
  • Version 1.1.0 and later do not write to browser storage. Earlier versions store the panel position in sessionStorage for that tab only.
  • Data is not sold, rented, or transferred to third parties.
  • Data is not used for creditworthiness or lending.

Permissions

The extension only requests access to https://mail.google.com/* so it can show message ID controls on Gmail. It does not request Chrome storage, identity, or broad host access.

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

Collapse a message to hide its ID row. In earlier versions, hide or collapse the floating panel at any time. Uninstalling the extension removes it from Chrome. Session data disappears when the tab is closed.

Changes

If this policy changes, this page will be updated and the effective date will change.
