Privacy Policy — Sync-Notes Pro

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 6 September 2026

What the extension does

Sync-Notes Pro stores short titled notes in the browser. Automatic sync writes those notes as JSON into your Google Drive plugin folder through a local native host.

Data collected

  • Note titles and bodies that you write
  • Selected page text if you use the shortcut to save a snippet

Storage and sharing

  • Notes are stored in Chrome extension storage.
  • Sync writes notes-state.json via native host com.cytracon.plugin_sync.
  • No Cytracon note server. Data is not sold.

Permissions

  • storage — local notes
  • activeTab / scripting — save selected text
  • downloads — export a JSON backup
  • nativeMessaging — Drive folder JSON
  • alarms — periodic sync

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

You can use the extension locally, export a backup, or uninstall it to remove local extension data from Chrome. Synced JSON files live in your own Google Drive folder and can be deleted there.

Changes

If this policy changes, this page will be updated and the effective date will change.
