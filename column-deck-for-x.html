Column Deck for X — Privacy Policy

Effective date: 20 October 2026
Publisher: Cytracon Webservices
Contact: bb@cytracon.com

Purpose

Column Deck for X displays native X pages in a personal multi-column dashboard and offers local layout and appearance filters. It is an independent extension and is not affiliated with X Corp., ReDeck, or Control Panel for Twitter.

Data processing

The extension processes the visible X page structure locally to size feeds, select native tabs and hide optional page elements. It stores only dashboard preferences and column configuration in Chrome local extension storage. Column configuration can include search terms, profile paths and list URLs that you choose. It does not store timelines, messages, passwords, cookies or access tokens.

The publisher does not receive, collect, sell, share or transfer your X content, browsing history or dashboard configuration. There are no analytics, advertising trackers, telemetry or publisher-operated backend services. No remote executable code is downloaded by the extension.

X sign-in and native pages

Native X pages use your existing X session and communicate directly with X. This activity is governed by X's own terms and privacy policy. The extension does not collect your sign-in credentials or authenticate to X on a publisher server.

Permissions

Chrome storage is used for local preferences. Access to x.com and twitter.com is used only to display and adapt the dashboard and its native X frames. Declarative network rules remove embedding restrictions only from marked dashboard subframe requests to those hosts. The extension does not modify response headers on ordinary X tabs or other websites.

Your choices

All appearance filters can be turned off. You can export your settings to a JSON file or replace them with an imported backup. Exports contain your chosen column URLs and settings; share them only with people you intend. Uninstalling the extension deletes its local Chrome storage. You can separately delete any exported files.

Limited use

Data is not sold to third parties, is not used or transferred for purposes unrelated to the extension's single purpose, and is not used or transferred to determine creditworthiness or for lending purposes.

Contact and changes

For questions contact Cytracon Webservices at bb@cytracon.com or www.cytracon.com. Changes to this policy will be posted on this page with an updated effective date.
