Privacy Policy — Cytracon Pinned Tabs

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 6 September 2026

What the extension does

This extension stores pinned-tab profiles (names, URLs, autostart) and reopens them in Chrome windows. Automatic sync writes that profile JSON into your Google Drive plugin folder through a local native host.

Data collected

  • Profile names, autostart flags, and the tab URLs you save

Storage and sharing

  • Profiles are stored in Chrome extension storage.
  • Sync writes profiles-state.json via native host com.cytracon.plugin_sync.
  • No Cytracon server receives the list. No advertising.

Permissions

  • tabs / windows — save and reopen pinned tabs
  • storage — local profiles
  • nativeMessaging — Drive folder JSON
  • alarms — startup cleanup and periodic sync

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

You can use the extension locally, export a backup, or uninstall it to remove local extension data from Chrome. Synced JSON files live in your own Google Drive folder and can be deleted there.

Changes

If this policy changes, this page will be updated and the effective date will change.
