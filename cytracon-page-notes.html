Privacy Policy — Cytracon Page Notes

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 6 September 2026

What the extension does

Cytracon Page Notes lets you attach private notes to an exact web page or an exact host. Notes stay in your browser. Automatic sync writes one JSON file into your Google Drive plugin folder through a local native host on machines you control.

Data collected

  • Current tab URL and title, used only to attach a note to that exact page or host
  • Note title, body, and tags that you write
  • Settings such as auto-sync and sync interval

The extension does not read page content beyond the URL/title needed for the note key, except when you use the keyboard shortcut to save currently selected text.

How data is used

Data is used only to save, search, export, import, and sync your notes. It is not used for advertising, profiling, creditworthiness, lending, or any purpose unrelated to page notes.

Storage and sharing

  • Local notes and settings are stored in Chrome extension storage.
  • Sync writes notes-state.json into your Google Drive folder BBachmann/Chrome Plugins/cytracon_page_notes/ via the local native host com.cytracon.plugin_sync.
  • No note server is operated by Cytracon. Notes are not sent to cytracon.com.
  • Data is not sold, rented, or transferred to third parties.

Permissions

  • storage — local notes and settings
  • activeTab / tabs — current URL/title and toolbar badge
  • scripting — save selected text via the keyboard shortcut
  • nativeMessaging — read/write the Drive folder JSON through the local host
  • alarms — periodic Drive file sync

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

You can use the extension locally, export a backup, or uninstall it to remove local extension data from Chrome. Synced JSON files live in your own Google Drive folder and can be deleted there.

Changes

If this policy changes, this page will be updated and the effective date will change.
