Privacy Policy — Cytracon Page Notes

Publisher: Cytracon Webservices · Contact: bb@cytracon.com · Effective: 17 August 2026

What the extension does

Cytracon Page Notes lets you attach private notes to an exact web page or an exact host. Notes stay in your browser. If you turn sync on, the extension writes one JSON file to the hidden app-data folder of your Google Drive.

Data collected

  • Current tab URL and title, used only to attach a note to that exact page or host
  • Note title, body, and tags that you write
  • Settings such as auto-sync and sync interval
  • If Drive sync is enabled: a Google OAuth token issued to your account, stored by Chrome

The extension does not read page content beyond the URL/title needed for the note key, except when you use the keyboard shortcut to save currently selected text.

How data is used

Data is used only to save, search, export, import, and optionally sync your notes. It is not used for advertising, profiling, creditworthiness, lending, or any purpose unrelated to page notes.

Storage and sharing

  • Local notes and settings are stored in Chrome extension storage.
  • Optional sync writes cytracon-page-notes.json to Google Drive appDataFolder for the signed-in user only.
  • No note server is operated by Cytracon. Notes are not sent to cytracon.com.
  • Data is not sold, rented, or transferred to third parties.

Permissions

  • storage — local notes and settings
  • activeTab / tabs — current URL/title and toolbar badge
  • scripting — save selected text via the keyboard shortcut
  • identity — optional Google Drive sign-in
  • alarms — optional periodic Drive sync
  • https://www.googleapis.com/* — Drive app-data file only

Remote code

The extension does not load remote code. All scripts ship inside the extension package.

Your choices

Notes work locally without Google. You can export JSON, import a backup, disconnect Drive, or uninstall the extension to remove local extension data from Chrome. Drive app-data can be removed from your Google account if you disconnect and delete that file.

Changes

If this policy changes, this page will be updated and the effective date will change.
